# 2026-05-21 — Agent Pattern Scan

## TL;DR
Three patterns today. The standout is n8n's Microsoft Agent 365 Trigger: agents get a real Entra ID, an inbox, a Teams presence, and SharePoint permissions, so a small operator can @mention "Jenn-Bot" in a shared channel and it pulls essay drafts and deadline status without anyone opening a dashboard. Most directly applicable to Jenn and the IEC vertical, since most counselors already live inside Microsoft 365 or Google Workspace.

## Patterns

### 1. The teammate-shaped agent with its own tenant identity — `jenn`, `ls-custom`, `caped`, `general`
*(tags: `iecs`, `test-prep`, `consultants`, `small-law-firms`, `accountants`)*

**Source:** n8n blog "Deploy n8n agents that show up as members of the team inside Microsoft apps" (https://blog.n8n.io/deploy-n8n-agents-that-show-up-as-members-of-the-team-inside-microsoft-apps/), n8n docs for the Microsoft Agent 365 Trigger node, Microsoft Learn Agent 365 identity docs, and the Pax8 SMB writeup. n8n shipped the Agent 365 Trigger in May 2026 and the SMB-tier license dropped to $15/user as a standalone add-on to Business Premium/Standard.

**Mechanism:** When you build an agent in n8n with the Agent 365 Trigger, the platform provisions a Microsoft Entra Agent ID for that workflow. The agent gets its own mailbox, directory entry, Teams presence, and manager relationship inside the tenant. Users invoke it three ways: @mention in a Teams channel, email it directly, or invoke it from Outlook/Word. The trigger fires on any of those events, hands the payload to an n8n workflow, the workflow calls native nodes, MCP servers, or sub-workflows (SharePoint, Outlook, OneDrive, the CRM, a database), and the agent posts back into the same Teams thread or replies on the email. Permissions are managed exactly like a human user — you grant it access to a SharePoint site or a Teams channel from the admin panel. It replaces the "person who pulls the file and answers the question in chat."

**Why agentic:** The agent isn't a chatbot stapled to a UI — it sits inside the channel where work already happens, holds permissions tied to its own identity, and can be granted or revoked like a contractor. The trigger is conversational, the action is whatever the workflow does, and there is no dashboard surface at all. Crucially, the same agent can be invoked across email, chat, and document apps without rebuilding the integration.

**SMB translation:** For Jenn (IEC). Trigger is a parent or student @mentioning "Jenn-Counsel" in the shared Teams or Google Chat space, or emailing it directly. The agent reads the family's CounselMore record, the essay folder in OneDrive, and the deadline tracker, and answers "where are we on Vanderbilt ED?" with the actual status and the next two tasks. Stack is Microsoft 365 Business Standard ($12.50/user) + Agent 365 standalone ($15) + n8n self-hosted or cloud (~$50/mo) + Claude API via MCP. Total under $200/mo for a solo counselor, $400/mo for a five-person practice. Replaces the manual "pull up the file, copy-paste the status, type the reply" loop the counselor does fifteen times a day between consults. Pitch: every family gets an instant accurate answer about their case without you opening a browser, and you get those four hours of inbox-triage time back to work on essays. Same pattern applies to a small accounting firm where the agent gets cc'd on client emails and answers "where is my W-2 in your queue?" against the document management system, or to Capital Educators where the agent answers "how did Maya do on the practice test yesterday?" against the LMS.

### 2. The practice-data agent that prompts the tutor to upsell — `caped`
*(tags: `test-prep`, `iecs`, `music-lessons`)*

**Source:** AlphaTest blog "Best AI SAT/ACT prep tools 2026: the adaptive revolution" (https://www.alphatestai.com/blog/197-best-ai-sat-act-prep-tools-2026-adaptive), SATCoach.ai, and a January 2026 academic implementation of a stateful tutor agent (MarkTechPost — Stateful tutor agent with long-term memory and adaptive practice generation). The shared pattern across the new wave of adaptive prep platforms is that they don't just adapt the student's practice — they generate outreach prompts back to the human tutor.

**Mechanism:** The agent ingests every student practice attempt — answer correctness, time-per-question, error type, topic tag — and maintains a rolling skill model per student. When the model detects a sustained weakness cluster (e.g. three consecutive sessions where the student misses quadratics-with-radicals at >40% but is otherwise on pace), the agent fires a notification to the tutor with a pre-drafted outreach: "Maya is stuck on quadratics with radicals — three misses across the last week. Suggest scheduling two 45-minute sessions before the August practice test. Reply 'send' to text her." Tutor replies 'send' and the agent SMSes the family, books the session into the tutor's calendar, and updates the student record. The trigger is the practice-data event; the action is a tutor-routed outreach plus a scheduling and CRM write. It replaces the role of the "study advisor" — the person who watches scores and decides when to escalate to more hours.

**Why agentic:** This is not a dashboard of student scores. The agent decides when intervention is warranted, drafts the language, and executes the booking once the tutor approves. The human stays in the loop only as a one-tap gate; everything else is workflow.

**SMB translation:** For Capital Educators (Debbie). Trigger is new practice-attempt data landing in their LMS (likely Canvas, Schoology, or a Bluebook export) on any of their 60–200 active students. Stack is the LMS export + a small Postgres rolling skill model + Claude with a tutoring-domain system prompt + Twilio for the SMS + Cal.com or Calendly for the booking + Stripe for the upsell. Around $300–600/mo for a practice that runs 100 students. Replaces the unpaid hour Debbie or a senior tutor spends every Sunday scanning scores and deciding who needs more hours. Pitch: every weak topic across your student base surfaces as a one-tap outreach prompt with a pre-drafted message and a one-click booking, so every score dip turns into a session before the family even notices it happened. The same mechanism works at a music studio like The Music Space — replace "practice score" with "practice-log entry from teacher notes" and the outreach becomes "Liam hasn't practiced four out of seven days, suggest a parent-tone check-in" — and at an IEC practice where the inputs are essay revision velocity rather than test scores.

Variation note: the 5/14 "complete sales agent workforce" pattern covered agent-driven outbound at the new-lead stage. This one is mechanically different — the trigger is post-sale customer behavior, the action is a retention/upsell touch, and the outreach is gated through the human practitioner rather than fired autonomously. Keep them separate in the inventory.

### 3. The supplier-watch agent that reads the news for you — `sollos` (variation of 2026-05-07 entry, new angle)
*(tags: `cpg`, `manufacturing`, `food-service`, `retail`)*

**Source:** Resilinc SC Watch agentic AI supply chain monitoring (https://resilinc.ai/products/agentic-ai-supply-chain-watch-sc-watch/), the January 2026 arxiv paper "Automating Supply Chain Disruption Monitoring via an Agentic AI Approach" (2601.09680), and AWS "Building resilient supply chains: multi-agent AI architectures for retail and CPG with Amazon Bedrock". The arxiv paper formalizes a seven-agent setup; SC Watch is the productized version pitched at mid-market and below.

**Mechanism:** A small set of specialized agents continuously scan unstructured external signal — news wires, regulatory filings, weather alerts, port-status feeds, customs notices, local social media — filtered against the company's actual supplier list and shipping lanes. When a signal matches (a strike at the Long Beach terminal where your contract manufacturer ships through, a flood at the prefecture where your tea is grown, a regulatory action at a co-packer), one agent classifies severity, a second maps the signal to specific POs and SKUs that depend on the affected node, a third drafts mitigation options (alternative supplier, expedited freight, customer pre-notification), and a coordinator routes the package to the operator with a one-tap approval. The trigger is the external signal landing in the monitored sources, not an internal inventory event. The arxiv result claims 48-hour advance warning for 60–75% of common disruption types and 5–10 staff hours per week recovered. The pattern replaces the operations person doing manual supplier status checks every morning.

**Why agentic:** Unlike the 5/7 supply chain pattern, which fired off internal inventory and demand data, this one runs entirely on external unstructured signal and only touches the internal system when surfacing recommendations. The agents make the connection between "headline" and "your SKU" — that connection is the whole product, and it's not something a dashboard can do.

**SMB translation:** For Sollos (yerba mate, pre-launch CPG). Trigger is monitoring the four to six supplier nodes that actually matter — the Brazilian/Argentine yerba grower, the co-packer, the can/glass supplier, the freight forwarder, the 3PL — across news in Portuguese/Spanish, port-status feeds, and a couple of trade publications. Stack is a Claude-driven n8n workflow scheduled every fifteen minutes, NewsAPI or RSS-feed scraping for the actual sources, a simple supplier-node table in Airtable or Postgres, and Slack/email for the alert plus one-click action. Around $200–400/mo at a pre-launch scale — radically cheaper than enterprise tools like Resilinc because Sollos only has six nodes to monitor, not six thousand. Replaces the unpaid morning ritual where Stephen reads ten trade newsletters and worries about whether anything affects him. Pitch: every morning you wake up to either "all clear" or "here's what changed overnight in your supply chain and here are the two emails I drafted to your co-packer about it." Same mechanism, scaled wider, fits a restaurant group monitoring food-supplier recall notices and a regional landscaping company monitoring fuel prices and equipment dealer inventory.

Variation note: This is a variation of the 2026-05-07 "supply chain agent workforce that thinks ahead" entry. The new angle is the input source — external unstructured signal (news, weather, port status, social) rather than internal inventory and demand data. Materially different mechanism even though the output (mitigation recommendation) overlaps.
