# 2026-06-19 — Agent Pattern Scan

## TL;DR
Three concrete patterns surfaced today, each representing a distinct action class: multimodal intake (Choco's OrderAgent parses email/SMS/image/PDF orders into ERP records for food distributors), pre-meeting briefing (Rippling's Salesforce-triggered ChatGPT Workspace Agent pulls Gong calls and account data into a Slack deal brief before morning sales calls), and outbound marketplace negotiation (Numeo cold-calls and email-negotiates with brokers on behalf of small trucking carriers). The negotiation pattern is the most novel — agents that *execute* outbound deals at SMB scale are still rare.

## Patterns

### 1. Multimodal order-intake agent for B2B distributors
**Source:** [Choco automates food distribution with AI agents — OpenAI customer story](https://openai.com/index/choco/) and [Choco + OpenAI Voice Agent press release](https://choco.com/us/press/choco-and-openai-join-forces-to-launch-the-first-ai-voice-agent-for-the-food-service-industry) — Choco's OrderAgent and VoiceAgent process 8.8M+ orders annually across food distributors, with reported 95% order accuracy and ~50% reduction in manual processing time.
**Mechanism:** Inbound message from a restaurant in any channel (email, SMS, attached spreadsheet, photo of a handwritten order, voicemail, live phone call) → agent extracts SKUs, quantities, delivery dates, customer ID → writes a structured order directly into the distributor's ERP → flags exceptions for a human → optionally upsells related products on live calls. Replaces the night-shift order taker who used to retype orders into the ERP after hours.
**Why agentic:** The agent decides between channels, resolves ambiguous SKU names against the distributor's catalog, recommends substitutions or add-ons in real time, and writes back to the system of record. It is not surfacing data for a human to act on; the order is committed.
**Generalizable core:** Inbound business message in any channel → agent normalizes against an internal catalog or schema → commits a structured record to the system-of-record → escalates only the edge cases.
**Deployability:** OpenAI Realtime API + a vertical SaaS (the distributor's ERP) + Twilio for phone + a queue for email/SMS. Roughly a month build for a single distributor; the harder work is the catalog normalization, not the LLM call. Translates directly to building-materials wholesalers (orders coming in by fax-PDF and contractor texts), medical supply distributors, and parts counters in auto-repair (calls from shops asking "do you have a left rear caliper for an '18 Tacoma"). Scale caveat: requires a clean SKU/catalog backbone; distributors with messy product data will spend more time on the normalization step than the agent itself.

### 2. Pre-meeting briefing agent triggered by CRM events
**Source:** [Rippling's sales opportunity agent, featured in OpenAI's Workspace Agents launch](https://openai.com/index/introducing-workspace-agents-in-chatgpt/) — built by a single Sales Consultant at Rippling with no engineering support, reportedly saving reps 5–6 hours per week.
**Mechanism:** New Salesforce opportunity created (or a scheduled 6am cron) → agent pulls the account from Salesforce, scrapes recent funding/news, fetches the latest Gong call transcript, and pulls prior deal notes → composes a structured deal brief (account context, last call summary, suggested talking points, open objections) → posts to the rep's Slack channel before the morning standup. Replaces the rep's manual hour of pre-call research, and the SDR-team Monday "deal review" prep.
**Why agentic:** It picks which calls and accounts to summarize based on a state change in the CRM, decides what context is relevant given the deal stage, and writes a multi-section brief that synthesizes multiple sources. The output is the artifact a rep walks into the meeting holding.
**Generalizable core:** State change in a system-of-record (or a schedule) → agent assembles cross-system context (CRM + transcript + email + external research) → drafts a structured briefing → posts to the channel where the human will see it before they need it.
**Deployability:** ChatGPT Workspace Agents or Claude + MCP connectors for Salesforce/Gong/Slack; alternately n8n with the same connectors plus a Claude/OpenAI node. Weekend build for a single-rep version, week build for a team rollout. Direct copies: a clinic owner gets a morning patient brief before each appointment (EHR + last call + outstanding labs), a property manager gets a pre-walkthrough brief on the unit and tenant (PMS + maintenance history + last text exchange), a litigator gets a pre-deposition brief on opposing witnesses from Westlaw + prior filings. No new infrastructure needed; this rides on whatever CRM/PMS/EHR the operator already runs.

### 3. Outbound marketplace negotiation agent for small carriers
**Source:** [Numeo AI customer stories — Four Ways Cargo (150 trucks) added ~$1,000/truck/month after adoption](https://numeo.ai/customers) and [Numeo pricing tier for small carriers ($99/mo, up to 10 trucks)](https://numeo.ai/) — a real SMB-priced deployment serving 1–20 truck operators alongside enterprise fleets.
**Mechanism:** Truck nearing drop-off (or scheduled "find next load" event) → agent scans DAT and other load boards for posted loads within range → ranks by profit per mile using the truck's home base and historical lane rates → drafts a market-backed counter-offer email to the broker, or places an outbound call to negotiate the rate live → reports results back to the dispatcher in the TMS, who chooses which booked load to accept. Replaces the dispatcher hours spent calling brokers, hunting load boards, and negotiating rates one at a time.
**Why agentic:** The agent acts as a counterparty — it goes outbound to third parties (brokers), produces a rate offer informed by real-time market data, and conducts the negotiation. This is different from intake or briefing patterns; it executes external transactions, not just summarizes information for humans.
**Generalizable core:** Internal asset becomes available (truck, room, slot, hour) → agent scans external marketplaces for matching opportunities → ranks by margin using historical performance → drafts or delivers personalized outreach with a negotiated offer → human approves the booked transaction.
**Deployability:** Numeo as a packaged product is the easiest path; for custom builds, the stack is load board API or scraper + Claude/OpenAI for offer drafting + Twilio or Vapi for voice + a TMS write-back. Month build to do it well, mostly because the rate-negotiation logic and load-board parsing have edge cases. Translates to: hotel revenue managers negotiating with OTAs and corporate accounts when rooms open up, freelance contractors auto-bidding on Upwork/RFP feeds with margin-backed quotes, electrical/plumbing supply houses auto-quoting contractors against material price feeds, dental practices auto-filling no-show slots by texting a ranked waitlist with personalized timing. Scale caveat: works only where there's a real marketplace with structured data and counterparties willing to transact with a non-human voice; less suited to relationship-heavy sales.
