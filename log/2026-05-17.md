# 2026-05-17 — Agent Pattern Scan

## TL;DR
The landscaping estimate-from-address agent takes a prospect's address from a web form and produces a priced, signable proposal in minutes by stitching satellite imagery, parcel data, and the contractor's own price book. This is the clearest cold-outreach pattern we've seen for landscaping yet — and the same mechanism (address → measured asset → priced quote) maps cleanly to pest control and other property-walked trades.

## Patterns

### 1. Address-to-priced-quote agent for landscaping — `landscaping`
**Source:** [QuoteIQ InstaQuote](https://myquoteiq.com/features/insta-quote/) and [Aspire PropertyIntel + ProMaps](https://www.youraspire.com/products/propertyintel) — small-business platform (QuoteIQ $189/mo) and the enterprise version (Aspire, used by $1M+ commercial landscapers) both shipped versions of this in the last year. Aspire customers report 85% more bids/week.
**Mechanism:** Trigger is a homeowner pasting a property address into a link on the contractor's site or social profile. The agent calls a property records API for parcel boundaries, fetches recent aerial imagery (Nearmap or equivalent), runs vision over the image to measure lawn/driveway/bed areas, looks up the contractor's price book and regional labor rates, generates a priced proposal with line items, sends it for e-signature, and on signature drops a scheduled job into the FSM dispatch system with the signed contract attached. The estimator's site visit is removed from the path entirely for routine residential work.
**Why agentic:** It's not a calculator. The agent makes real decisions — which boundaries to trust, which service templates to apply at this lot size, which upsells to attach — and it triggers a downstream action (job creation in dispatch) without a human in between. A dashboard would surface the address and let a person quote it; this quotes it and books it.
**SMB translation:** Sell to 5–20 truck residential landscapers in the cold-outreach pipeline. Realistic trigger: a "Get a quote in 60 seconds" link on their Squarespace/GoDaddy site or in their Google Business Profile. Realistic stack: Next.js form → Regrid or ATTOM parcel API + Nearmap or Google aerial imagery → Claude vision for measurement → contractor's price book in Airtable → DocuSign for e-sign → push job to Jobber or HouseCall Pro via webhook. Replaces the owner driving to the property for the estimate, plus the office manager's quote prep time. Pitch sentence: "Your website starts quoting and booking residential mowing while you're on a truck — you only show up for the high-ticket walks."

### 2. Autonomous menu-rewrite agent for restaurants — `restaurants`
**Source:** [Deliverect AI launches autonomous menu agents](https://www.fastcasual.com/news/deliverect-ai-debuts-autonomous-workforce-to-manage-menus-protect-digital-revenue/) — April 2026. Brands on the platform include KFC, Burger King, Taco Bell, Pret. A separately deployed Deliverect agent autonomously designed, deployed, and optimized a KFC promo that produced a 118% sales lift end-to-end with no human in the loop.
**Mechanism:** Trigger is continuous — every new order. The agent reads live POS and delivery-platform order data per location, identifies which items are converting and which aren't, then directly rewrites the live digital menu: reorders item position, hides underperformers, surfaces upsells, attaches promotional copy. It writes back to the menu config in DoorDash/UberEats/the restaurant's POS, not to a dashboard for a manager to review. The "menu engineering" task that an outside consultant used to do quarterly now happens daily at the location level.
**Why agentic:** This is the meaningful step beyond Square Managerbot (logged 5/14): Managerbot surfaces insights and recommends actions to a human; the Deliverect menu agent rewrites the menu itself. The decision and the action are both inside the loop. It's also distinct from voice ordering agents (logged earlier) — same vertical, completely different surface area.
**SMB translation:** Sell to single-location and 2–5 location independent restaurants on Toast or Square with active DoorDash/UberEats menus. Realistic trigger: Toast/Square POS webhook on every order, batched into daily reads. Realistic stack: Toast or Square POS API → Claude API for menu decisions against last 30 days of orders → DoorDash/UberEats merchant APIs to push menu updates → Slack notification to the owner when a position change is shipped, with a one-click rollback. Around $200–400/month. Replaces the menu engineering consultant ($2–5k engagement, runs once a year) and the owner's nightly POS-report habit. Pitch sentence: "Your menu re-orders itself every morning based on what actually sold yesterday, so the items that pay your rent are always front and center on every platform."
