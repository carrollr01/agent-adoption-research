# 2026-10-21 — Agent Pattern Scan

## TL;DR
Motive's fleet Agents (launched Oct 19) ship the most interesting new skeleton: sensor telemetry crosses a threshold, an AI assistant calls the right human directly in-channel, and a work order gets created in the maintenance system in parallel. The same trigger-to-outbound-call-plus-system-write pattern is the piece most SMB shops are still doing by hand — a dispatcher watching a dashboard and then picking up the phone.

## Patterns

### 1. Telemetry-triggered driver outreach plus work order creation
**Source:** [Motive launches Agents, SiliconANGLE, Oct 19 2026](https://siliconangle.com/2026/10/19/motive-launches-agents/) and [Motive press release coverage, Waste360](https://www.waste360.com/fleet-technology/motive-launches-agents-ai-that-acts-before-problems-start) — Motive, a US fleet-ops platform used by trucking and services fleets, rolled out "Agents" to existing customers on launch day.
**Mechanism:** Customers configure a condition (fatigue warning signs, engine fault code, HOS risk, specific DVIR entries). When Motive's telemetry hits that condition, an Agent spins up, pulls the vehicle and driver context, has the Atlas voice assistant call the driver in-cab to check in or guide action, opens a work order in the maintenance system with the fault code and recommended work, and escalates to the manager if the driver doesn't respond or the issue needs human approval.
**Why agentic:** The sequence runs without a dispatcher in the loop and the agent picks which humans to involve based on severity and response. It is not a dashboard that pings a manager — it decides to place an outbound voice call and writes a work order on its own.
**Generalizable core:** sensor/telemetry threshold → agent assembles vehicle/person context → outbound voice call to the operator in the field + task record in the system of record → human only when it escalates.
**Deployability:** Enterprise today (Motive customers), but the pattern lands directly at SMB field-service scale. HVAC/plumbing shops with GPS-telemetry trucks (Samsara, Verizon Connect, Fleetio) can trigger an outbound Vapi/Retell call to the tech plus a ServiceTitan or Housecall Pro job when a van alert fires, or a weekend after-hours tech-callout agent. Weekend build on n8n or Make. Replaces the on-call dispatcher reading alerts and relaying by phone.

### 2. Photo-in, graded-rating-out quality control agent
**Source:** [Albertsons AI-powered produce inspection tool, Google Cloud press, May 13 2026](https://www.googlecloudpresscorner.com/2026-05-13-Albertsons-Companies-Announces-AI-Powered-Supply-Chain-Tool-to-Further-Enhance-Produce-Quality-Control-and-Consistency); [Albertsons AI produce inspection, Supermarket News](https://www.supermarketnews.com/grocery-technology/albertsons-now-has-ai-powered-produce-inspection-system) — reinforced in Google's Oct 2026 Gemini at Work recap as a live deployment in select Albertsons distribution centers for berries and grapes.
**Mechanism:** Inspector uploads a photo of inbound produce. The agent scores it against Albertsons' internal visual quality standards (color, blemish, uniformity), returns a rating with an accept/reject recommendation, logs the decision to the quality system, and flags trending supplier issues when ratings drift. Human inspector reviews and approves before the pallet moves.
**Why agentic:** The agent is doing the subjective judgment call that used to depend on which inspector was on shift, and routing anomalies back to supplier records. It's not a reporting layer — the output changes whether product ships.
**Generalizable core:** image/doc uploaded at a handoff point → agent scores against a stored spec → rating + decision written into the system of record → human approves at the edges only.
**Deployability:** Albertsons built it in-house on Gemini Enterprise + Vision — enterprise-scale and distribution-center-scoped today. SMB adaptations are cheaper to copy because the "spec" is small: a restaurant checking a daily produce delivery against Toast's inventory expectations (phone photo at receiving → Claude vision call → accept/reject in inventory + credit request draft to supplier), a used-car lot grading trade-in condition for pricing (walkaround video frames → damage report + initial offer), a dental lab grading incoming impressions before the tech starts work. Weekend-to-week build on Claude or Gemini API + a form on a shared iPad. Replaces the senior inspector doing it on gut feel.

### 3. User-triggered pre-decision fraud check
**Source:** [Starling Bank Scam Intelligence press release](https://www.starlingbank.com/news/scam-intelligence-launch/) and [Banking Exchange coverage](https://m.bankingexchange.com/news-feed/item/10451-starling-bank-launches-uk-first-ai-tool) — Starling launched the feature in-app in late 2025, called out again in Google's Oct 2026 Gemini at Work roundup where Starling reports fraud cancellations up ~4x since launch.
**Mechanism:** Before sending money, the customer uploads a screenshot of the marketplace listing, seller profile, or message thread. The agent analyzes the content against known scam patterns (price-too-good signals, image reverse-search, bank-detail/seller-name mismatch, pressure/urgency language), writes a personalized explanation with the specific red flags found, and recommends whether to proceed. The customer makes the final call; Starling cites a 4x lift in fraud cancellations.
**Why agentic:** This is a per-transaction judgment the user used to make alone (or ask a friend about), compressed into a check the agent runs on arbitrary artifacts the user hands it. The output isn't a score; it's reasoned per-item guidance.
**Generalizable core:** user uploads suspicious artifact at a decision point → agent evaluates against a known-pattern library → returns reasoned, specific guidance → user decides.
**Deployability:** Starling built on Google Cloud + Gemini; the pattern copies down to SMB with any multimodal model. Real-estate agents and property managers can let prospective landlords upload applicant pay stubs / IDs / rental history screenshots for a pre-background-check sniff test (Claude Sonnet + a prompt template that encodes the common forgery signals, output into Buildium notes). Insurance brokers can let customers submit screenshots of a quote they got elsewhere; the agent flags coverage gaps and non-standard clauses before the customer commits. Weekend build with a web form, a vision-capable model, and a shared prompt. Replaces the senior person who used to eyeball-check "does this look right."

### 4. Event-triggered templated document generation from a master contract
**Source:** [Google Cloud Gemini at Work 2026 announcement](https://cloud.google.com/blog/products/ai-machine-learning/welcome-to-gemini-at-work-2026) — Grupo Bafar, a Mexican foodservice/retail group with ~400 Carnemart stores, runs a contract agent that generates operational annexes for new store openings in 17 minutes vs 140 minutes manually.
**Mechanism:** A new store entering the pipeline triggers the agent (a status change in the real-estate/legal workflow, almost certainly a project-management tool). It reads the master contract plus the specific store's data (location, format, local terms, operating hours), generates the operational annex matching the master's clauses to the store's facts, and routes it into the signature workflow. Legal signs off instead of drafting from scratch per store.
**Why agentic:** The agent is doing document assembly against a parameterized spec, not filling a template — it has to pull the right clauses, resolve the local overrides, and know when to escalate ambiguity. The humans move to approval only.
**Generalizable core:** new child-record created in a repeatable program → agent reads the master template + the child's parameters → generates the derived document → routes for human sign-off.
**Deployability:** Grupo Bafar's scale makes this worth building; SMB versions are smaller but just as useful. Franchise operators generating per-unit opening packets (new franchisee added in HubSpot → agent builds the franchise agreement addendum, operations manual annex, and local lease rider), small law firms with high-volume templated engagements (new matter opened in Clio → agent drafts the engagement letter and conflict-check memo), HR consultancies issuing per-employee compensation agreements for a client (new hire in Gusto → agent generates offer letter, PIIA, and benefits elections). Week-long build with Claude API + a master-doc store (Google Drive or a vector store) + a doc-generation step (Google Docs API or pdfkit). Replaces the paralegal or ops person who drafts "the same letter, but customized" dozens of times.
