Agent Pattern Scan — 2026-09-05 — 5 patterns: proactive-SMS finance agent (Rowan), autonomous monthly close (Pilot Meridian), CRM-embedded sales agent (Claudeforce), vertical drafting agent (EvenUp), autonomous contract lifecycle (Spellbook)

https://github.com/carrollr01/agent-adoption-research/blob/claude/determined-meitner-bqpjl9/log/2026-09-05.md

The standout pattern this run is Rocket Money's Rowan, launched Sept 3 with Anthropic. A background agent watches the user's account activity, detects specific event classes (free trial about to bill, recurring charge increased, forgotten subscription, savings opportunity), and proactively SMS-texts the user with a proposed action. The user replies in plain language, and Rowan executes: cancels the subscription, opens a renegotiation session, or moves money to savings. It's the cleanest example this year of "proactive outbound to the human, same-channel authorization back, then agent acts." The generalizable core — continuously watched data stream → detected event → outbound message with proposed action → plain-language authorization → agent executes — is our most useful takeaway of the run and applies far beyond fintech.

Four other patterns qualified. Pilot's Meridian (June 23) runs an SMB's full month-end close autonomously, escalating only for judgment calls with material dollar impact — the same skeleton fits any period-close process (property management, insurance commissions, PS timesheet roll-ups). Claudeforce (Salesforce + Anthropic, Aug 27) puts a Claude plugin on top of the CRM that generates interactive dashboards on the fly and writes back with per-action-type autonomy controls (ask-before / auto-send / auto-write, field-scoped) — a template for replacing dashboards with agent-generated interactive views on any operational system. EvenUp cuts personal-injury demand drafting from 15 hours to 15 minutes by long-context reasoning across full medical record bundles with cited inputs shown in the draft — same skeleton fits insurance claim workups, M&A diligence, grant apps, disability determinations. Spellbook's Autonomous Contract Management (June 30) runs three chained workflows (Intake, Review, Insight) with a dedicated per-negotiation workspace holding the full history of each deal, plus a post-signature monitor tied to extracted obligation dates — architecture pattern transfers to RFP negotiations, insurance claims, PO back-and-forth.

The broader signal: the Aug 26-27 cluster of Anthropic customer stories (Rocket Money, EvenUp, Spellbook, plus Legora/Harvey/Eve Legal/Gamma) suggests the vertical-agent buildout is now producing usable case material rather than pure marketing. Zapier consolidated its standalone Agents into "AI by Zapier" (migration through Aug 15). Relay.app is shutting down (paid access ends Sept 14) — check if anything of ours runs on it.
