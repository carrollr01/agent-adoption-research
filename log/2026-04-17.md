# 2026-04-17 — Agent Pattern Scan

## TL;DR
The highest-leverage port today: take Avoca's inbound-voice-booking pattern (proven in HVAC/plumbing/electrical at 400+ bookings a week) and copy it into independent dental, veterinary, and small medical practices. Operationally identical surface (phone-heavy, calendar-constrained, expensive front desk), near-zero agent penetration, ~200k practices in the US.

Also today: a Slack-emoji-as-work-order pattern from Stripe that ports cleanly into any paper-heavy professional-services SMB, a KPI narrative agent that replaces the Monday report in hospitality and fitness, a stateful standup collector for field workforces, and a supplier-delay pager that ports from enterprise CPG down to independent restaurants.

## Patterns

### 1. Reaction-as-trigger task handoff — source: `software` | ports: `healthcare`, `professional-services`
**Source:** [How Stripe built "minions"](https://www.lennysnewsletter.com/p/how-stripe-built-minionsai-coding) — How I AI, Steve Kaliski, 2026-03-25. Stripe ships ~1,300 PRs/week via this pattern.
**Mechanism:** An engineer adds a specific Slack emoji reaction to a message (bug report, screenshot, ask). The reaction is the trigger. An agent spins up an isolated cloud dev env, reads the thread for context, makes the change, opens a PR with a backlink. No form, no ticket, no branch-cutting.
**Why agentic:** The trigger is an ambient in-flow human signal (one click in the tool you already use), context is pulled from the surrounding conversation, and the action produces an artifact in a different system. There is no dashboard to check.
**Port — healthcare (independent clinics, dental, vet):** Trigger: a label in the practice's shared Gmail or patient-portal inbox (`draft-reply`, `refill-review`, `records-request`). Agent reads the thread, the relevant chart note from the EMR (Dentrix/Eaglesoft/Jane/Kareo), and the last message sent to that patient. Drafts a reply in the provider's voice as a Gmail draft or portal message, pings the MA or provider "draft ready for Mrs. Garcia." Stack: Gmail/portal API + Claude API + thin MCP shim over the EMR + Apps Script label watcher. $200–400/mo. Replaces: the MA/front-desk person spending 90 min/day triaging and drafting patient messages. Pitch: "Label the message. Get a chart-aware draft. The provider signs, or edits, or declines — but never starts from blank."
**Port — professional-services (independent accountants, CPAs, bookkeepers):** Trigger: Gmail label on client emails (`k1-chase`, `extension-question`, `tax-notice`). Agent reads the thread, the client's prior-year return from the firm's document management system (Canopy, Karbon, SmartVault), and the last message sent. Drafts a reply citing the specific line item or notice. Stack: Gmail + Claude API + Karbon/Canopy API, ~$150/mo for a two-partner firm. Replaces: the partner's 7 pm triage session. Pitch: "Every client email becomes a labeled work order. You get a draft grounded in their actual file."

### 2. KPI narrative agent (anti-dashboard Monday report) — source: `software` | ports: `hospitality`, `fitness`
**Source:** [AI-powered Slack workflows for PMs who hate dashboards](https://blog.logrocket.com/product-management/ai-powered-slack-workflows-for-product-managers) and the concrete Friday-4-PM example at [Cotera](https://cotera.co/articles/slack-workflow-builder-advanced-guide).
**Mechanism:** Scheduled trigger reads a KPI sheet plus the agent's own prior-week post. Computes deltas, identifies where change is concentrated, writes a summary with causal framing ("support volume up 23%, highest WoW since January, concentrated in Salesforce connector issues"). Posts to Slack.
**Why agentic:** It does not display numbers; it names the driver and compares against its own prior post. Synthesis, not a chart.
**Port — hospitality (independent restaurants, small hotel groups):** Trigger: Monday 7 AM cron. Reads Toast/Square/Resy POS export, labor data from 7shifts, and last week's agent post. Posts one message per location to the owner's SMS or WhatsApp: "Labor ran 34% vs. 28% target, driven by Friday/Saturday bar overstaffing. Tuesday covers down 18% — that's the fourth Tuesday in a row. Top-selling item swapped from salmon to short-rib burger." Stack: Toast API or CSV drop + Claude API + Make/n8n. ~$40–60/mo. Replaces: the Monday-morning GM writing a recap nobody reads. Pitch: "You already have the POS. Stop opening it. The conclusions show up on your phone before you open the store."
**Port — fitness (independent gyms, studios, Pilates/yoga chains):** Trigger: Monday 6 AM cron. Reads Mindbody/ClassPass/Mariana Tek exports: class fill, new signups, cancellations, no-shows. Owner gets a text: "Class fill flat 62%. New signups +4, all from the 6 AM Tuesday cohort. Noon classes dropped to 28% fill — fifth week. Jenna's 7 AM Tuesday up 80%." Stack: Mindbody API + Claude API + Twilio. ~$30/mo. Replaces: the owner logging into Mindbody for an hour on Monday. Pitch: "One text tells you which class to cut and which instructor to keep."

### 3. Standup-collector with follow-up enforcement — source: `software` | ports: `trades`, `healthcare`
**Source:** [Cotera — Slack Workflow Builder Topped Out at Step 3](https://cotera.co/articles/slack-workflow-builder-advanced-guide). Standup agent DMs at 9 AM, nudges non-responders at 9:45, escalates to manager on a third skip in a week.
**Mechanism:** Scheduled prompt per person. Tracks who replied. DMs non-responders at +45. Keeps a rolling count across the week. On threshold, DMs the manager with the specific pattern ("Jen skipped Mon/Wed/Fri"). Stateful, conditional escalation.
**Why agentic:** It remembers. A Google Form or webhook cannot count skips, escalate differently based on count, and produce a specific explanation.
**Port — trades (HVAC, electrical, plumbing, landscaping — the mid-size crew with 6–20 techs):** Trigger: Friday 4 PM, agent SMSes each tech with their week's completed jobs pre-filled from ServiceTitan/Housecall Pro/Jobber. Reply captures notes per job. Nudges at Sat 10 AM if missing. Pings the ops manager Sunday night with the laggards. Notes auto-file into each job record so photos + notes are one tap from the invoice. Stack: ServiceTitan API + Twilio + Claude API, ~$80/mo. Replaces: the ops manager chasing techs by text on a Sunday. Pitch: "The techs get one SMS with their jobs listed. You stop being the nag. Invoices go out with real notes."
**Port — in-home healthcare (visiting nurses, home health aides, hospice):** Trigger: end-of-shift SMS with the day's visit list pre-filled. Reply captures visit notes per patient. Non-responders nudged 90 minutes later. Notes auto-file to the agency's EMR (WellSky, MatrixCare). Stack: EMR API + Twilio + Claude API, ~$100/mo. Replaces: the nurse completing charting at home after an 11-hour shift. Pitch: "Visit notes arrive by SMS. Charting finishes before she gets to the car. Compliance goes up. So does retention."

### 4. Inbound voice booking agent — source: `trades` | ports: `healthcare`, `hospitality`
**Source:** [Owned and Operated #173 — Avoca AI](https://www.ownedandoperated.com/post/owned-and-operated-173-we-booked-400-calls-a-week-how-avoca-ai-is-shaping-home-services). Newer episode [#194](https://open.spotify.com/episode/48Q1HXXG25F8mHT4RVVJyl).
**Mechanism:** Call router forwards inbound and after-hours calls to a voice agent. Agent reads: caller history (repeat?), tech/provider calendar, service-area + pricing guardrails. Qualifies, books, confirms via SMS, writes to CRM as a new job. Declines or defers when rules require. Multi-turn conversation consulting live systems — not a phone tree.
**Why agentic:** The agent holds a real conversation, queries external systems live, and takes different actions based on what it learns.
**Port — healthcare (independent dental, veterinary, small medical practices):** Trigger: SIP forward on ring-no-answer and after-hours. Agent reads: patient history in Dentrix/Eaglesoft/ezyVet/Kareo, provider calendar, insurance guardrails. Books cleanings, re-exams, first-available slots; routes emergencies to on-call; handles prescription refill requests by filing a task. Writes back to the PMS. Stack: Vapi or Retell + Claude API + PMS API (Dentrix has an open API; ezyVet has one; Kareo via NPI/SMART-on-FHIR). $300–700/mo. Replaces: the front-desk person answering evenings and the afternoon lull they can't staff. Pitch: "You already pay for new-patient acquisition. Stop losing the 38% who call after 5."
**Port — hospitality (independent restaurant reservations, small salon chains):** Trigger: inbound and after-hours call forward. Agent reads OpenTable/Resy availability, existing reservations, house rules, deposit requirements. Books the table, moves a VIP, offers alternates when full. Stack: Vapi/Retell + Claude + Resy/OpenTable API. $200–500/mo. Replaces: a host declining 15 reservations a week because the landline went unanswered. Pitch: "Friday at 7:14 pm someone called to book a 6-top. You lost them. This agent didn't."

### 5. Supply-chain ping agent — source: `cpg-enterprise` | ports: `hospitality`, `construction`
**Source:** [Crisp Launches AI Agents for CPG Brands and Retailers](https://www.businesswire.com/news/home/20260211212237/en/Crisp-Launches-AI-Agents-to-Drive-Shareholder-Value-for-CPG-Brands-and-Retailers) — Feb 2026.
**Mechanism:** Agent monitors distributor/retailer inventory and sell-through feeds. Detects low inventory at a specific DC or velocity spike on a SKU. Drafts a concrete replenishment recommendation (units, DC, date) and contacts the retail buyer directly with the ask. It reaches out — enterprise tooling surfaces the same alert on a dashboard and waits.
**Why agentic:** The outreach is the work. Detection is the easy part.
**Port — hospitality (independent restaurants, small QSR chains):** SMB restaurants have no distributor telemetry; flip the direction. Trigger: daily cron + Gmail/SMS watcher on Sysco, US Foods, Restaurant Depot, and specialty-supplier threads. Reads: Toast/Square sales velocity on spoilable SKUs, on-hand sheet in Google Sheets or MarketMan, co-packer/supplier emails. Action: when forecast exceeds on-hand for short-shelf-life items, or when a supplier email contains delay language ("pushed," "OOS," "substituting"), agent drafts a text to the owner or chef with the SKU, the gap, and the suggested move (call supplier B, sub this cut, 86 the special). Stack: Gmail + Sheets + Claude + Twilio. ~$40/mo. Replaces: the Sunday-night inventory spiral and the Wednesday 86-list scramble. Pitch: "You don't need an ERP. You need a pager that wakes up before service does."
**Port — construction (small GCs, specialty-trade contractors):** Trigger: Gmail watcher on lumber yard, supply house, and subcontractor threads. Reads: project schedule in Buildertrend/CoConstruct/Procore, PO status, expected delivery dates. Action: when a supplier email contains delay language or when a delivery date slides past the scheduled install, agent drafts a message to the PM with the project, the affected trade, and the crew that needs rescheduling. Stack: Gmail + Buildertrend API + Claude + Twilio. ~$80/mo. Replaces: the PM discovering the framing package is three days late when the framers show up. Pitch: "Find out before the crew does."
