Agent Pattern Scan — 2026-07-23 — 5 patterns | Record-once-replay-forever EHR agent

Full log: https://github.com/carrollr01/agent-adoption-research/blob/main/log/2026-07-23.md

Five concrete deployments today, all mechanism-level. The standout is Beacon Health, a YC W26 primary-care ops agent live against a 40,000-patient IPA. A practice manager screen-records themselves doing a workflow once in the EHR — clicking through Athena or Epic, filling a prior-auth form, writing a chart note — and Beacon captures the sequence as an executable policy. From then on, the agent replays that workflow across the entire panel whenever a triggering event fires (a screening comes due, a referral is needed, a gap-in-care surfaces). No API integration. It also submits to payer portals and sends patient SMS. This inverts the "screen-watching to write SOPs" pattern already in the log: the recording is the executable policy, not documentation of one. Playwright / Browserbase + step graph + assertion checks per screen. Month build. Value model only holds in at-risk / value-based practices where gap closure carries P&L.

Pattern two is PLAN0, a construction estimation agent with ~$20B of projects run through it. Trigger is a plans upload — PDFs or DWGs. Vision models read floor plans, elevations, and MEP sheets; the agent joins extracted quantities against a proprietary and partner-fed database of localized historical unit costs, maps to CSI cost codes, and outputs a line-item estimate plus scenario analytics (swap materials, stress-test against overrun history). Two-to-six weeks of manual estimator work collapses to minutes. The generalizable skeleton — unstructured visual document + reference-price corpus → structured priced deliverable — carries directly to cabinetry shops, sheet-metal fabricators, and print shops. The moat is the reference data, not the model.

Third is FurtherAI at a top-tier US Managing General Agent (~$1.5B written premium, ~$20B TIV processed, ~2,000 hours saved in three months). Broker email hits the submissions inbox with 100–200 pages of attachments — ACORD forms, statements-of-values, loss runs, engineering PDFs. The agent extracts fields to schema, gap-checks against appetite rules, drafts a broker reply for missing items, and routes down one of three paths: auto-quote, escalate, or decline. Clearance drops from ~32 minutes to ~1 minute. The pattern — inbound email with heterogeneous document attachments → extract + gap-check → auto-reply + route — is one of the highest-leverage skeletons in the log. It fits wholesale RFQs, personal-injury legal intake with medical records, freight brokerage quote packets, and commercial real estate loan submissions. Week-to-month build; expect 3–6 weeks of schema tuning per new document class.

Fourth is JBGoodwin REALTORS, a 900-agent Texas brokerage hiring ~300 people a year. Candidate applications hit a form; Zapier's Email Parser extracts fields; an AI step enriches the candidate from public sources (prior brokerage, recent market activity), builds a HubSpot contact, writes a Zapier Tables row for pipeline analytics, and DMs the market-specific recruiter on Slack. Recovers ~25% of a recruiter's day. Weekend-to-week build; the value is the recruiter starting the first call already informed. Same skeleton fits any inbound-form workflow — lead intake, vendor onboarding, event-signup triage.

Fifth is TTEC Digital's deployment for Compass Working Capital on Salesforce Agentforce Contact Center — the first live Salesforce customer on that product. Nonprofit doing financial coaching; ~6,000 staff hours/year reclaimed. The trigger is a call connecting. The agent streams the live transcription, joins it against the client's Salesforce record, and during the call it auto-populates CRM fields, creates follow-up tasks, schedules callbacks, and routes to the correct coach if the conversation shifts. This is a new angle on the voice-agent pattern in the log: the human stays on the call, the agent does the back-office work in parallel. Real-time transcription (Deepgram / AssemblyAI / Whisper streaming) + Claude with MCP to CRM + Twilio, or Retell/Vapi with tool-use during the call. Week-to-month build. HIPAA/PII audit logging is table stakes in finance and health.

Access notes worth flagging: X/Twitter, Reddit, and most YC / Anthropic / OpenAI / Vapi / Retell customer-story pages were 403 or login-walled to WebFetch this run. Everything above is corroborated through secondary reporting where the primary page wouldn't load. If we want Reddit and X as reliable sources rather than intermittent ones, we need an authenticated MCP path — WebSearch and WebFetch alone are not enough.
